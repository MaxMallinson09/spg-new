# Password display font

Atkinson Hyperlegible Mono Bold is bundled unmodified from the
[Google Fonts source repository](https://github.com/googlefonts/atkinson-hyperlegible-next-mono).
It is served locally and used only for the generated password display.

- Source file: `fonts/webfonts/AtkinsonHyperlegibleMono-Bold.woff2`
- Upstream Git blob SHA: `7a4bb5a6c2a114df6e5b2bc76e6070a9ca978841`
- Licence: SIL Open Font License 1.1, reproduced in `AtkinsonHyperlegibleMono-OFL.txt`.

The original character shapes are retained to help distinguish similar letters
and numbers. System monospace fonts remain as fallbacks while it loads.
